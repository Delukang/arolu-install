# Arolu 客户版安装

本仓库仅提供安装入口、说明和许可。业务源码保存在私有仓库；客户安装包通过 GitHub Releases 发布。

## 安装

使用专用的 Ubuntu 24.04 x86_64 服务器，准备 sudo 权限和可访问的公网 IPv4，并长期放行 TCP 80、443。安装会配置 PostgreSQL、Nginx、HTTPS 证书及 Arolu 服务，请勿在承担其他业务的主机上直接执行。

唯一安装命令：

```bash
curl -fsSL https://raw.githubusercontent.com/Delukang/arolu-install/main/install.sh | sudo bash
```

## 安装时会发生什么

- 不需要填写 IP。安装程序通过两个独立来源核对公网 IPv4，并显示识别结果；查询失败或地址不一致时停止。不会为服务器分配新的 IP，也不提供手动覆盖参数。
- 普通 NAT 不因网卡上没有公网 IP 而被拒绝。端口或网络映射未就绪时等待；无法确定的网络问题会如实提示。取得并部署 HTTPS 证书前，不开放明文登录。
- 引导脚本固定发布公钥和安装程序哈希，先验签再执行。后续程序与软件包只从 GitHub Releases 下载。下载、签名、版本或哈希核对失败即停止，请检查原因后重试，不改装旧版本。
- 安装需要下载运行依赖。首次密码、验证器配置和恢复码仅在服务器私有 SSH 终端交付，请妥善保存，不要贴到公开讨论中。
- 已安装实例重复执行时保留身份、密码和账本；有新版本时按安装器的升级流程处理，不会自动清空客户数据。

## 登录与服务账本

安装完成后，按终端显示的 HTTPS 地址登录。添加交易所账户前，请核对账户权限和交易参数。服务账本提供授权状态、用量、充值单及迁移控制；具体收费以授权中心发布的规则为准。充值需按页面给出的链、代币合约、收款地址和精确金额自行付款，安装脚本不会发起转账。

## 开放范围与尚未验证项

客户版开放代码支持的全部11个交易所实例及全部现有功能：币安、OKX、Gate、Bitget、Hyperliquid、Aster、Bybit、Ondo、QFEX、Lighter Robinhood、Lighter。各实例启用开关均打开，使用你自己绑定的账户；不附带pilot、liveTrials、试点卡片、标的或金额范围，也不按验收进度删减功能。

代码自身的检查仍生效，包括账户模式、身份与权限、行情时效、资金和敞口、请求预算及授权收费规则。不支持的账户模式仍会拒绝下单。

当前验证缺口仅供了解，不作为功能开关：

- 本次编译版未逐一完成11实例及其不同账户模式下的真实下单、订单确认、平仓和有在途订单时的重启恢复实测；源码版历史实盘记录不能替代客户编译版的实盘结果。
- 充值功能开放，但本批未进行真实资金充值到账测试。
- 本批尚未完成手机页面、15分钟资源测量及跨版本升级回退演练；本批无旧版用户，仅验证新命令全新安装。以后给已有用户更新前须完成下面的升级验证。
- 外部告警通知尚未开发；不影响现有页面状态与错误提示。

## 更新发布规则

给已有用户发布更新前，维护者须在专用测试环境完成“安装上一版 → 升级到新版”验证。编译、回放和安装检查不等于真实交易验收。

安装入口可公开查看；Release 内第三方库的许可证随包提供。许可范围见 LICENSE。
